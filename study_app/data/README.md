# Data used by the study application

- `movies.csv`, `ratings.csv`: the MovieLens "ml-latest-small" dataset from GroupLens Research,
  University of Minnesota (https://grouplens.org/datasets/movielens/). Redistributed under the MovieLens
  license terms; please cite F. Maxwell Harper and Joseph A. Konstan. 2015. The MovieLens Datasets: History
  and Context. ACM TiiS 5, 4, Article 19. https://doi.org/10.1145/2827872
- `movie_metadata.json`: the movies the application can show, with title, year, genres, an IMDb rating and a
  poster URL retrieved from the OMDb API. Ratings and poster links belong to their providers and are included
  only so the application can render the page.
